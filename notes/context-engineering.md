# 上下文工程：让 Agent 不「失忆」也不「撑爆」

（演示用笔记，内容仅为说明 examples，不作为事实依据）

## 三类手段

上下文工程通常包括三类手段：写入（把信息沉淀到外部存储）、
选择（按需捞回相关信息）、压缩（用摘要替换冗长历史）。

## 写入选择

短期笔记（scratchpad）放在 state 里，适合当前任务；
长期事实放在 store 里，适合跨会话复用。
不要把长期事实塞进 system prompt，那会持续消耗 token。

## 压缩触发

常见触发条件是消息条数或 token 数阈值。
触发后用一次模型调用生成摘要，再用摘要替换旧消息，
保留最近若干条原文以维持上下文连贯。
